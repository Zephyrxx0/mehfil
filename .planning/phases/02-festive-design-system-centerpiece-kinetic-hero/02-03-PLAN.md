# Plan 02-03: Responsive Workspace Shell, Change Explainer & Smooth Crossfade

<objective>
**As a** celebration host adjusting event details,  
**I want to** navigate a responsive workspace featuring a 3-pane desktop split (35% Budget, 40% Timeline, 25% Change Explainer), a 4-tab mobile layout (`[Budget, Timeline, Style, Summary]`) with a persistent bottom drawer sheet for change history, view plain-language paise rebalancing deltas with One-Click Undo, and enjoy a seamless animated crossfade between the Landing Hero and the Plan Workspace,  
**so that** planning my celebration is effortless, transparent, responsive on any screen size, and completely reversible at any moment.
</objective>
