## Color

Strict 3-hue festive palette discipline. Pastels are exclusively fills and ambient cards; text is always high-contrast Royal Plum (`#3A2442`). White text on pastels is strictly forbidden.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8EE` (Warm Ivory) | Viewport canvas, modal backdrop surfaces, family share view background |
| Secondary (30%) | `#FBF2E3` (Soft Ivory) / `rgba(58, 36, 66, 0.08)` hairline border | Card surfaces, sheet drawers, modal panels, segmented tabs, QR code container fill |
| Accent (10%) | `#F2A7B8` (Gulabi Rose) | Reserved strictly for Protected Moment showcases and lock indicators (see explicit list below) |
| Primary CTA | `#F7C873` (Marigold) | Key action buttons ("Copy Private Edit Key", "Share Plan via WhatsApp", "Add Ceremonies to Calendar") |
| Destructive | `#D95D39` (Terracotta) | "Regenerate Share Link" confirmation action, conflict warning banner, offline badge |
| Ink / Text | `#3A2442` (Royal Plum) | All typography, icons, hairline structural dividers, focus rings |
| Success / Cloud | `#4A7C59` (Cardamom Green) | "● Saved to Cloud" status indicator dot, "Link Copied!" micro-feedback confirmation |

### Accent Reserved For (Strictly 10%)
Gulabi Rose (`#F2A7B8`) is strictly reserved for:
1. Protected Moment feature card fill and highlight pill in the Family Share View (`/share/[token]`).
2. "Protected Moment held firm" tag and lock icon in deterministic version diff cards.
3. Protected priority ring in the celebration category breakdown card.

It is never used for general buttons, generic borders, or random backgrounds.

### Accessibility & Contrast Contract
- Royal Plum (`#3A2442`) on Warm Ivory (`#FFF8EE`): **11.8:1** (Exceeds WCAG AAA).
- Royal Plum (`#3A2442`) on Marigold (`#F7C873`): **7.4:1** (Exceeds WCAG AAA).
- Royal Plum (`#3A2442`) on Gulabi Rose (`#F2A7B8`): **6.8:1** (Exceeds WCAG AAA).
- Cardamom Green (`#4A7C59`) on Warm Ivory (`#FFF8EE`): **5.2:1** (Exceeds WCAG AA).
- Terracotta (`#D95D39`) on Warm Ivory (`#FFF8EE`): **4.8:1** (Exceeds WCAG AA).

## Detailed Component Specifications

### 1. Top-Bar Sync Status Badge (`SyncStatusBadge.tsx`)
- **Container:** Rounded pill `rounded-full border border-royal-plum/10 bg-warm-ivory px-3 py-1 flex items-center gap-2 text-sm font-medium text-royal-plum shadow-2xs`.
- **States:**
  - `cloud_saved`: Solid dot `w-2 h-2 rounded-full bg-[#4A7C59]` (Cardamom Green), text: "Saved to Cloud", accompanied on change by a 300ms fade checkmark icon.
  - `syncing`: Hollow ring `w-2 h-2 rounded-full border-2 border-[#F7C873] animate-pulse` (Marigold), text: "Syncing...".
  - `local_saved`: Terracotta lightning icon `w-3 h-3 text-[#D95D39]`, text: "Saved Locally".
- **Interaction:** Hovering reveals a Radix Tooltip explaining the exact persistence state and last sync timestamp.

### 2. Share & Save Modal (`ShareSaveModal.tsx`)
- **Trigger:** Button in top bar: `rounded-full bg-warm-ivory border border-royal-plum/15 hover:bg-warm-ivory/80 text-royal-plum px-4 py-2 text-sm font-semibold flex items-center gap-2`.
- **Dialog Container:** `rounded-3xl border border-royal-plum/10 bg-warm-ivory p-6 max-w-lg shadow-xl`.
- **Tab Navigation:** Radix Tabs with 2 pills: "Organizer Edit Key" (Tab 1) and "Family Share Link" (Tab 2). Active pill has Marigold `#F7C873` wash with subtle Plum ring.
- **Tab 1: Organizer Edit Key:**
  - Capability URL Box: Read-only input with masked or truncated token `bookmymehfil.vercel.app/plan/abc...#key=••••`, accompanied by primary button: "Copy Private Edit Key".
  - QR Code Section: Centered white-padded card `p-4 rounded-2xl bg-white border border-royal-plum/8 inline-block shadow-2xs` containing 160x160 SVG QR code pointing to `/plan/[id]?key=[token]`.
  - QR Subtext: "Scan with phone camera to resume editing on mobile" (`text-sm text-royal-plum/70`).
  - WhatsApp Self-Share Button: Secondary ghost pill `rounded-full border border-royal-plum/15 px-4 py-2 text-sm font-semibold hover:bg-royal-plum/5 flex items-center justify-center gap-2`.
- **Tab 2: Family Share Link:**
  - Informational Callout: Muted Ivory card with Lock icon: "Sanitized View: Strips vendor contract prices, draft notes, and contingency margins."
  - Share URL Box with "Copy Family Share Link" button.
  - WhatsApp Group Share Button: Marigold pill with WhatsApp icon: "Share Plan via WhatsApp".
  - Link Invalidation Bar: Divider followed by text-button in Terracotta: "Regenerate Share Link". Clicking launches an `AlertDialog` confirmation dialog before firing the server invalidation.

### 3. Capability Router & Read-Only Downgrade Dialog
- **Route:** `/plan/[id]`
- **Auto-Claim Flow:** If `?key=[token]` exists in URL:
  - Invisible claim request sent to `/api/plan/[id]/claim`.
  - On success, `mehfil_edit_[id]` cookie is established.
  - Instant `router.replace('/plan/' + id)` cleans URL bar in <50ms without re-triggering page reload.
- **Downgrade Banner:** If visitor has no edit cookie and no valid key:
  - Top bar displays amber-tinted badge: `🔒 Read-Only View`.
  - Next to badge: button "Unlock Organizer Editing".
  - All workspace sliders and inputs render in disabled/inert state with hover cursor `cursor-not-allowed`.
- **Unlock Dialog:**
  - Radix Dialog centered on screen.
  - Headline: "Enter Organizer Edit Key".
  - Input field with autofocused cursor.
  - Submitting checks key validity; on success, reloads workspace with full editing capabilities.
  - On failure, displays inline error: "This edit key does not match this celebration. Please verify the URL or ask the host for an updated key."

### 4. Family Share Celebration Page (`/share/[token]`)
- **Route:** `/share/[token]`
- **Layout:** Single-column editorial story layout (`max-w-3xl mx-auto px-4 py-12 flex flex-col gap-10`).
- **Elements:**
  1. **Celebratory Header:** Wordmark "महफ़िल | Mehfil" in Tiro Devanagari Hindi, followed by celebration title in Fraunces 36px Bold, event date formatted in natural style ("December 18, 2026"), city, and guest count pill.
  2. **Event Countdown Banner:** Soft Marigold pill with clock icon: "45 days until celebration".
  3. **Protected Moment Showcase:** Gulabi Rose `#F2A7B8` card (`rounded-3xl p-6 border border-royal-plum/10`):
     - Badge: "Cherished Priority"
     - Title: "Our Protected Moment: {Category Name}"
     - Description: "This sacred celebration element is non-negotiable and guaranteed in our planning harmony."
  4. **High-Level Category Breakdown:** High-level pie/progress proportion visual showing whole Rupee totals (`₹X,XX,XXX`) and percentage allocations. Raw vendor quotes and internal margins are completely absent.
  5. **Ceremony Timeline:** Vertical timeline rail with Marigold celebration nodes showing public milestone ceremonies (Haldi, Mehendi, Sangeet, Pooja, Main Wedding, Reception).
  6. **Filtered Calendar Export CTA:** Sticky bottom or footer primary action button: "Add Ceremonies to Calendar (.ics)" (`h-12 px-6 rounded-full bg-marigold text-royal-plum font-semibold text-sm shadow-md hover:scale-[1.02] active:scale-[0.98] transition-transform`).
- **Expired State View:** If `share_key_hash` is invalidated by regeneration:
  - View renders a centered calm editorial card: "Celebration Link Expired".
  - Subtext: "The celebration organizer has refreshed this link. Please request the latest share link from the host."
  - Action: "Return to Mehfil Home".

### 5. Version History & Undo Explainer Cards
- **Desktop Location:** Pane 3 (Right Column, `col-span-3`).
- **Mobile Location:** Bottom Sheet / Mobile Drawer Tab "Revisions".
- **Card Structure:**
  - Header: "Version History" with version count badge (`v{latestVersionNumber}`).
  - List Container: Reverse-chronological scroll container (`max-h-[500px] overflow-y-auto space-y-3 pr-1`).
  - Card Item:
    - Top row: Version chip `v{N}` (`font-semibold text-sm px-2 py-1 rounded-md bg-royal-plum/5 text-royal-plum`), relative timestamp ("Just now", "5 mins ago"), and `Current` badge on the active version.
    - Narrative diff sentence: Plain-language deterministic diff formatted cleanly:
      - e.g. "Scaled guest count to 250 (+50 guests). Scaled Catering by drawing from Decor (-₹15,000); Protected Moment held firm."
    - If Protected Moment held firm: subtle Gulabi Rose chip with Shield icon: `Protected Moment held firm`.
    - Action CTA (for any past version $k < N$): Compact button `h-8 px-3 rounded-full border border-royal-plum/15 text-sm font-semibold hover:bg-royal-plum/5 flex items-center gap-1`:
      - Icon: `RotateCcw`
      - Label: "Restore Version {k}"
- **Forward Restore Execution:**
  - Clicking "Restore Version {k}" triggers a non-destructive forward commit of `v(N+1)`.
  - State matches snapshot $k$.
  - Change description logs: "Reverted to v{k} ({reason})".
  - A subtle celebratory checkmark pulses on the newly created top card.

### 6. Optimistic Concurrency Conflict Banner
- **Placement:** Top of workspace immediately beneath navigation bar.
- **Appearance:** Rounded card `rounded-2xl border border-[#D95D39]/30 bg-[#FFF8EE] p-4 flex flex-col sm:flex-row items-start sm:items-center justify-between gap-3 shadow-md`.
- **Icon & Copy:** Terracotta alert triangle icon with text: "Plan updated from another device — your local draft is out of sync."
- **Action Group:**
  - Button 1: "Refresh to Latest Plan" (Ghost button with Plum border: discards stale local draft and reloads server version).
  - Button 2: "Commit as New Snapshot" (Primary Marigold button: forces commit of current local state as a new forward version).
