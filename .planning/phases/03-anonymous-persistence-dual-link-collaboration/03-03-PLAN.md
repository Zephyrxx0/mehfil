# Plan 03-03: Deterministic Diff Engine, Version History & Forward Restore Undo

<objective>
**As a** celebration organizer,  
**I want to** observe instant UI updates (<10ms) while an interaction-end debounced queue (800ms / `onPointerUp` / `onBlur`) creates immutable version records with deterministic plain-language change summaries, review revisions in a reverse-chronological timeline with Protected Moment tags in Pane 3 / Mobile Bottom Sheet, and restore any previous snapshot with a 1-click forward append-only undo,  
**so that** our celebration budget history is completely audit-trailed, tamper-evident, and mathematically resilient with zero loss of previous states or LLM hallucination latency.
</objective>

<behavior>
- Test 1: Diff engine calculates integer paise deltas across all categories between `prevPlan` and `nextPlan`.
- Test 2: Guest count change outputs exact sentence: `"Scaled guest count to {N} ({+ΔG} guests). Scaled {recipients} by drawing from {donors}; Protected Moment held firm."`
- Test 3: Total budget change outputs: `"{Increased|Decreased} total budget by {formatINR(abs(ΔB))}; apportioned across flexible lines; Protected Moment held firm."`
- Test 4: Protected Moment lock outputs: `"Locked Protected Moment for {category}; non-negotiable floor enforced"` with `isFloorProtected = true`.
- Test 5: Forward restore action outputs: `"Reverted to v{k} ({previousReason})"`.
- Test 6: Zero LLM latency: computation executes deterministically in <1ms without network calls.
</behavior>
<action>
1. Implement `src/lib/engine/diff.ts` (citing D-12, ADR-0004):
   - Export interfaces `PlanDiffInput` and `PlanDiffResult`.
   - Function `computePlanDiff(input: PlanDiffInput): PlanDiffResult`:
     - Compares `prevPlan` and `nextPlan` lines by matching line IDs and calculating `deltaPaise = nextLine.currentPaise - prevLine.currentPaise`.
     - Identifies recipient categories (`deltaPaise > 0`) and donor categories (`deltaPaise < 0`).
     - Checks if Protected Moment held firm (`isFloorProtected = Boolean(nextPlan.brief.protectedCategory)`).
     - Formats amounts with Indian currency grouping via `formatINR`.
     - Handles 5 deterministic action types:
       1. `restore`: `"Reverted to v${restoredVersionNumber} (${restoredReason})"` (citing D-10).
       2. `protected_lock`: `"Locked Protected Moment for ${category}; non-negotiable floor enforced"`.
       3. `guest_scale`: `"Scaled guest count to ${nextG} (${signG} guests). Scaled ${recipients.join(', ')} by drawing from ${donors.join(', ')}${protectedSuffix}."`.
       4. `budget_change`: `"${actionVerb} total budget by ${formatINR(abs(deltaB))}; apportioned across flexible lines${protectedSuffix}."`.
       5. `manual` / fallback: `"Adjusted allocations across ${deltas.length} categories${protectedSuffix}."`.
2. Create unit test suite `tests/engine/diff.test.ts` exercising all 5 mutation types, donor/recipient tracking, Indian currency formatting, and edge cases (no change, identical budgets).
</action>
