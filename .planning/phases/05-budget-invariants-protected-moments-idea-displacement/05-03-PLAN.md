<threat_model>
## Threat Model Mitigation
- **T-05-08 (Modal Lockout & Interaction Trap):** Infeasible budget state blocks organizer from adjusting other inputs or navigating tabs. *Mitigation:* Permissive Shortfall architecture (ADR-0002) renders an informational banner at top of budget and timeline tabs without blocking inputs or navigation.
- **T-05-09 (Haptic API Failure & Device Incompatibility):** Calling `navigator.vibrate` on unsupported desktop browsers or secure contexts throws exceptions. *Mitigation:* Wrapped in feature detection `if (typeof navigator !== 'undefined' && 'vibrate' in navigator)` preventing runtime errors.
- **T-05-10 (Undo State Desynchronization):** Clicking Tier 1 instant undo restores stale or partial state. *Mitigation:* Undo operation rolls back to the verified preceding immutable version snapshot via `persistence.restoreVersion` / `setPlan(previousVersion)` with full diff audit trail.
</threat_model>
