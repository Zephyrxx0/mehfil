1. Implement `src/lib/engine/quote-guard.ts` (citing D-05, D-07, D-08):
   - Implement `parseAnchorNumber(anchor: string): number | null`:
     - Normalizes text: strips currency symbols (`₹`, `Rs`, `INR`, `/-`), commas, and spaces.
     - Parses words/abbreviations: handles "Lakh" (`* 100,000`), "k" (`* 1,000`), "crore" (`* 10,000,000`).
     - Extracts candidate numeric values and returns raw Rupee amount.
   - Implement `verifyVerbatimEvidence(rawText: string, rawItems: RawQuoteItem[], guestCount: number)`:
     - Normalizes `rawText.toLowerCase()`.
     - Phase 1: Case-insensitive normalized substring match. If `!rawText.toLowerCase().includes(sourceAnchor.toLowerCase())`, drop item with `reason: 'no_substring_match'`.
     - Phase 2: Numeric snippet parsing. If `parseAnchorNumber(sourceAnchor) === null` or differs from `amountStated` by more than 0.01, drop item with `reason: 'numeric_mismatch'`.
     - For verified items: calculate pure integer paise (`amountStated * 100`, scaled by `guestCount` if `pricingType === 'per_guest'`).
     - Returns `{ verifiedItems: ExtractedQuoteItem[], droppedItems: QuoteDroppedItem[], baseTierPaise: Paise }`.
   - Implement `buildPackageTiers(extractedTiers: RawPackageTier[], rawText: string, guestCount: number)` assembling complete `PackageTier[]` with verified items, base tier paise, and dropped items.

2. Implement `src/lib/engine/omission-rules.ts` (citing D-06):
   - Implement `detectQuoteOmissions(rawText: string, category: BudgetCategory, baseTierPaise: Paise): QuoteOmissionAdder[]`:
     - Normalizes text for keyword evaluation.
     - **Catering:**
       - Check for `gst included`, `inclusive of taxes`, `net rate`. If missing: adder `+5% Catering GST estimate` (`rateType: 'percentage'`, `percentageValue: 5`, `amountPaise: Math.round(baseTierPaise * 0.05)`).
       - Check for `service charge`, `servers`, `waitstaff`, `corkage`. If missing: adder `Waitstaff & Service: ₹8,000` (`rateType: 'fixed'`, `fixedPaise: 800_000`, `amountPaise: 800_000`).
     - **Services (Decor, Photo, Venue, Entertainment/DJ):**
       - Check for `gst included`, `all taxes included`. If missing: adder `+18% GST estimate` (`rateType: 'percentage'`, `percentageValue: 18`, `amountPaise: Math.round(baseTierPaise * 0.18)`).
     - **Venue / Decor (Lawn / Outdoor):**
       - Check for `generator`, `dg set`, `power backup`, `genset`. If missing: adder `Generator Power Backup: ₹15,000` (`rateType: 'fixed'`, `fixedPaise: 1_500_000`, `amountPaise: 1_500_000`).
     - **Entertainment / DJ / Venue:**
       - Check for `overtime`, `after 10 pm`, `curfew`, `extended hours`. If missing: adder `Overtime buffer (after 10 PM): ₹10,000` (`rateType: 'fixed'`, `fixedPaise: 1_000_000`, `amountPaise: 1_000_000`).
     - **Photo & Film:**
       - Check for `travel included`, `stay included`, `accommodation`. If missing: adder `Crew travel & stay buffer: ₹15,000` (`rateType: 'fixed'`, `fixedPaise: 1_500_000`, `amountPaise: 1_500_000`).
     - All adders initialize with `isEnabled: false`.
   - Implement `calculateTierTotalWithAdders(tier: PackageTier, adders: QuoteOmissionAdder[], activeAdderIds?: string[]): Paise`.

3. Write test suites:
