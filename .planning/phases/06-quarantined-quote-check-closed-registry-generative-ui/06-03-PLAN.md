<action>
1. Extend `src/lib/ai/schemas.ts` with Closed Registry Generative UI schemas (citing D-13, ADR-0008):
   - Define `GenerativeUIComponentEnum`:
     - `'VendorChecklist'`
     - `'IdeaGrid'`
     - `'QuoteReport'`
     - `'ScenarioComparison'`
   - Define `LayoutVariantEnum`:
     - `'compact'`
     - `'detailed'`
     - `'side_by_side'`
   - Define `GenerativeUISectionSchema`:
     - `id: z.string()`
     - `component: GenerativeUIComponentEnum`
     - `variant: LayoutVariantEnum`
     - `title: z.string().min(1).max(100)`
     - `rationale: z.string().min(10).max(500)`
     - `lineIds: z.array(z.string()).optional()`
     - `quoteIds: z.array(z.string()).optional()`
     - `ideaIds: z.array(z.string()).optional()`
     - `highlightEntityId: z.string().optional()`
     - Chain `.strict()` so that any presence of numeric keys (`amount`, `cost`, `price`, `paise`) or dates fails validation immediately.
   - Define `GenerativeUILayoutSchema`:
     - `layoutTitle: z.string().min(1).max(100)`
     - `layoutSummary: z.string().min(10).max(500)`
     - `sections: z.array(GenerativeUISectionSchema).min(1).max(4)`
     - Chain `.strict()`.

2. Implement Generative UI layout orchestration in `src/lib/ai/orchestrator.ts` (citing D-15, ADR-0007):
   - Implement `generateDeterministicLayout(plan: Plan, contextCategory?: BudgetCategory): GenerativeUILayout`:
     - Constructs a standard static layout using active `plan.lines` and available quotes.
     - Section 1: `QuoteReport` (or `ScenarioComparison` if multiple quotes exist for category).
     - Section 2: `VendorChecklist` mapping open and committed lines.
   - Implement `generateLayoutWithFallbackLadder(plan: Plan, prompt: string, contextCategory?: BudgetCategory, options?: FallbackLadderOptions)`:
     - Tier 1: Gemma 4 (`gemma-4-31b-it`) with 8s timeout and 1-shot repair.
     - Tier 2: Gemini 2.0 Flash (`gemini-2.0-flash`).
     - Tier 3: `generateDeterministicLayout` with `activeTier: 3` and toast message "Viewing standard comparison layout".
     - Guarantees 0% blank screens during demos and network partitions.

3. Write test suite `tests/ai/generative-ui.test.ts`:
   - Verifies `GenerativeUISectionSchema` accepts valid entity ID descriptors (`lineIds`, `quoteIds`, `ideaIds`).
   - Verifies `GenerativeUISectionSchema` strictly REJECTS numeric amount and date props (`amount: 50000`, `date: '2026-12-01'`).
   - Verifies only allowlisted components (`VendorChecklist`, `IdeaGrid`, `QuoteReport`, `ScenarioComparison`) pass schema validation.
   - Verifies fallback ladder returns static template on timeout, malformed JSON, or schema rejection.
</action>

   - Props: `{ lineIds?: string[]; highlightEntityId?: string; onSelectLine?: (lineId: string) => void; onCheckQuote?: (category: BudgetCategory) => void }`.
   - Client Resolution: Resolves lines from active `plan.lines`.
   - Displays vertical stack of category rows:
     - Category icon and name.
     - Allocated baseline in whole Rupees (`formatINR(line.currentPaise)`).
     - Status: Open pill with "Check Quote" trigger OR Marigold "Committed: {Vendor}" badge with variance pill.

2. Implement `src/components/quotes/registry/IdeaGrid.tsx` (citing D-13, D-16):
   - Props: `{ ideaIds?: string[]; highlightEntityId?: string; onAdoptIdea?: (idea: CuratedIdea) => void; onRetractIdea?: (ideaId: string) => void }`.
   - Client Resolution: Resolves idea objects from `CURATED_IDEAS` catalog, checking whether idea is present in `plan.adoptedIdeas`.
   - Renders 2-column responsive grid with idea cards:
     - Idea title and cultural nuance tag.
     - Cost range in integer Rupees.
     - Donor displacement tag ("Funds from: Misc & Decor").
     - Interactive Action: `Adopt Idea (+₹XX,XXX)` or `Retract Idea` with spring animation and immediate budget rebalance dispatch.

3. Implement `src/components/quotes/registry/QuoteReport.tsx` (citing D-13, D-16):
   - Props: `{ quoteId?: string; onCommitQuote?: (tierId: string, adders: string[]) => void; onUnlockQuote?: () => void }`.
   - Client Resolution: Resolves quote object from quote store or plan state.
   - Comprehensive dossier card:
     - Verified line items with verbatim Marigold pills (`Source: "..."`).
     - Stated inclusions and exclusions.
     - Interactive statutory omission chips (GST, Generator, Overtime) dynamically updating totals.
     - Live plan impact preview bar.
     - Commit Quote / Unlock Quote button.

4. Implement `src/components/quotes/registry/ScenarioComparison.tsx` (citing D-13, D-16):
   - Props: `{ quoteIds?: string[]; lineId?: string; onSelectScenario?: (quoteId: string, tierId: string) => void }`.
   - Client Resolution: Resolves 2-3 quotes for the same category from store or sample fixtures.
   - Renders multi-column comparison matrix (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`):
     - Column headers: Vendor Name & Package Tier.
     - Stated rates: Flat vs per-guest rates computed for `plan.brief.guestCount`.
     - Statutory adders comparison (GST inclusion, generator backup, curfew buffer).
     - Net budget impact vs category baseline.
     - Action button: `Select This Scenario` committing that quote and tier to the plan.

   - Verifies `ScenarioComparison` renders multi-vendor columns with pure client-computed numbers.
