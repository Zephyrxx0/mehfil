<action>
1. Implement quote commitment and displacement math in `src/lib/engine/budget.ts`:
   - Implement `export function previewQuoteDisplacement(plan: Plan, quote: VendorQuote, tierId: string, activeAdderIds?: string[])`:
     - Calculates `committedPaise` for selected tier and active omission adders.
     - Identifies target budget line matching `quote.category`.
     - Calculates delta: `deltaPaise = committedPaise - targetLine.currentPaise`.
     - If `deltaPaise <= 0` (savings or equal): returns `{ deltaPaise, displacedDonors: [], wouldTriggerShortfall: false, shortfallPaise: 0 }`.
     - If `deltaPaise > 0` (excess outlay):
       - Identifies eligible donor lines: `line.lineType === 'flexible'`, `!line.isProtected`, `!line.isCommitted`, and `line.id !== targetLine.id` (citing D-12, ADR-0004).
       - Sorts donors by `elasticityRank` ascending: Rank 1 Misc -> Rank 2 Entertainment -> Rank 3 Decor.
       - Iterates through donors calculating available headroom above 40% floor (`Math.round(donor.baselinePaise * 0.40 / 100) * 100`).
       - Tracks donor deductions and remaining needed paise.
       - If available capacity across all flexible donors is insufficient, sets `wouldTriggerShortfall = true` and records `shortfallPaise`.
       - Returns simulated displaced donors and shortfall state.
   - Implement `export function commitQuote(plan: Plan, quote: VendorQuote, tierId: string, activeAdderIds?: string[]): Plan`:
     - Creates shallow copy of lines.
     - Calculates `committedPaise` and finds target line.
     - Computes `deltaPaise = committedPaise - targetLine.currentPaise`.
     - If `deltaPaise > 0`:
       - Drains flexible donor lines in elasticity order down to 40% floor.
       - Protects lines with `isProtected === true` (inviolable, never trimmed).
       - If donor capacity runs out, triggers Permissive Shortfall (citing D-12, ADR-0002):
         - Clamps donors to 40% floor.
         - Target line receives full `committedPaise`.
         - Sets `plan.isInfeasible = true`.
         - Sets `plan.shortfallPaise = remainingDeficit`.
         - Calculates `plan.remedies = calculateShortfallRemedies(plan, plan.shortfallPaise)`.
     - If `deltaPaise < 0` (under budget savings):
       - Restores previously trimmed flexible lines back toward baseline.
       - Allocates any leftover surplus to `contingency` (Buffer).
       - Invariant holds: `sum(lines.currentPaise) === plan.totalBudgetPaise`.
     - Locks target line commitment fields (citing D-10):
       - `line.isCommitted = true`
       - `line.committedQuoteId = quote.id`
       - `line.committedVendor = quote.vendorName`
       - `line.committedTierName = tier.name`
       - `line.committedPaise = committedPaise`
       - `line.currentPaise = committedPaise`
       - `line.variancePaise = line.baselinePaise - committedPaise`
       - `line.committedAt = new Date().toISOString()`
     - Appends entry to `plan.quotesHistory` or state tracking.
   - Implement `export function unlockQuote(plan: Plan, category: BudgetCategory): Plan` (citing D-10):
     - Resets `line.isCommitted = false` and clears commitment fields.
     - Restores baseline allocation or rebalances flexible lines.

2. Implement timeline synchronization in `src/lib/engine/timeline.ts` (citing D-11):
   - Map each category to its primary milestone booking task:
     - `venue` -> `task_venue_contract` ("Lock Venue & Date Contract")
     - `catering` -> `task_catering_tasting` ("Catering Tasting & Menu Lock")
     - `photo_film` -> `task_photo_book` ("Book Lead Photographer & Cinematographer")
     - `decor` -> `task_decor_concept` ("Finalize Decor & Floral Visuals")
     - `entertainment` -> `task_entertainment_permit` ("Book Music, DJ & Sound Permits")
     - `favors` -> `task_invites_dispatch` ("Dispatch Digital & Physical Invites")
   - Implement `export function completePrimaryBookingTask(schedule: TimelineSchedule, category: BudgetCategory, quoteId: string): TimelineSchedule`:
     - Finds corresponding task and sets `task.isCompleted = true`, `task.originQuoteId = quoteId`, `task.completedAt = new Date().toISOString()`.
   - Implement `export function reopenPrimaryBookingTask(schedule: TimelineSchedule, category: BudgetCategory): TimelineSchedule`:
     - Re-opens task (`task.isCompleted = false`) on quote unlock.

3. Write test suite `tests/engine/quote-commitment.test.ts`:
   - Verifies committing a quote locks `currentPaise` and records `variancePaise`.
   - Verifies positive variance ("Saved ₹25,000") restores flexible lines and buffers contingency.
   - Verifies negative variance triggers elastic donor trimming in rank order (Misc -> Entertainment -> Decor).
   - Verifies Protected Moment lines are never displaced during quote commitment.
   - Verifies donor lines never drop below 40% baseline floor.
   - Verifies exceeding donor capacity triggers Permissive Shortfall and calculates 3 remedies.
   - Verifies timeline milestone booking task is completed and linked to `quoteId`.
   - Verifies unlocking quote restores line state and re-opens timeline task.
