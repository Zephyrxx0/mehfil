| 3xl | 64px | Sheet top clearance, celebratory completion banner padding, layout vertical margins |

## Typography

Strict 4-size typographic hierarchy declared across all Phase 06 components:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 28px (1.75rem) | 700 (Bold) | 1.15 | Smart Inspector title, celebration completion modal hero, tier total showcase |
| Heading | 20px (1.25rem) | 600 (SemiBold) | 1.25 | QuoteCheckCard vendor title, section headers, scenario comparison column titles |
| Body | 16px (1.0rem) | 400 (Regular) & 500 (Medium) | 1.5 | Unstructured text paste area, plan impact narrative descriptions, rationale text |
| Label | 14px (0.875rem) | 500 (Medium) & 600 (SemiBold) | 1.4 | Package tier selector tabs, verbatim source pills, omission chips, variance badges |

Typographic rules:
- **Headings & Display:** `Fraunces, Georgia, serif`
- **Body & Labels:** `Plus Jakarta Sans, -apple-system, BlinkMacSystemFont, sans-serif`
- **Cultural Wordmarks & Accents:** `Tiro Devanagari Hindi, serif`
- **Numerals & Currency:** `Plus Jakarta Sans` with `font-variant-numeric: tabular-nums` (`tnum`) formatted strictly with Indian digit groupings (`₹1,50,000` or `₹950/plate`).
- **Text Color:** All text is rendered in Royal Plum (`#3A2442`). White text (`#FFFFFF`) on Marigold or Gulabi Rose pastels is **strictly prohibited** (violates DESIGN.md §2.3).

## Color

Strict 3-hue festive palette discipline. Pastels are exclusively fills and ambient cards; text is always high-contrast Royal Plum (`#3A2442`).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8EE` (Warm Ivory) | Viewport background, modal surfaces, card bodies, clean negative space |
| Secondary (30%) | `#FBF2E3` (Soft Ivory) / `rgba(58, 36, 66, 0.08)` hairline border | Nested intake wells, secondary card surfaces, slide-over panels, tab containers |
| Accent (10%) | `#F7C873` (Marigold) & `#F2A7B8` (Gulabi Rose) | Celebratory focus, interactive adders, committed states, and Protected Moments |
| Primary CTA | `#F7C873` (Marigold) | Key primary actions ("Commit Venue Quote", "Extract Quote Breakdown") |
| Destructive | `#D95D39` (Terracotta) | "Unlock / Replace Quote" confirmation action, budget shortfall warnings |
| Ink / Text | `#3A2442` (Royal Plum) | All typography, icons, hairline structural borders, tab focus rings |
| Success / Verified | `#4A7C59` (Cardamom Green) | Verbatim anchor matched checkmarks, task completion badges, savings variance |
| Amber Warning | `#E09F3E` (Amber) | Dropped unanchored items alert pill, unstated cost indicators |

### Accent Reserved For (Strictly 10%)
Marigold (`#F7C873`) and Gulabi Rose (`#F2A7B8`) are strictly reserved for:
1. Primary CTA button fill (`#F7C873` Marigold with `#3A2442` Plum text).
2. Verbatim source anchor badge pills (`#F7C873` Marigold with `#3A2442` Plum text).
3. Active package tier selector tab highlight (`#F7C873` Marigold wash).
4. Interactive omission adder chip active toggle state (`#F7C873` Marigold wash).
5. Protected Moment budget line highlight wash and shield badge (`#F2A7B8` Gulabi Rose).
6. "Committed Quote" badge on locked budget line cards (`#F7C873` Marigold).
7. Real-time plan impact preview displacement bar (`#F7C873` Marigold).

Accent is never applied to general body text, generic card backgrounds, or unselected lists.

### Accessibility & Contrast Contract
- Royal Plum (`#3A2442`) on Warm Ivory (`#FFF8EE`): **11.8:1** (Exceeds WCAG AAA).
- Royal Plum (`#3A2442`) on Marigold (`#F7C873`): **7.4:1** (Exceeds WCAG AAA).
- Royal Plum (`#3A2442`) on Gulabi Rose (`#F2A7B8`): **6.8:1** (Exceeds WCAG AAA).
- Cardamom Green (`#4A7C59`) on Warm Ivory (`#FFF8EE`): **5.2:1** (Exceeds WCAG AA).
- Terracotta (`#D95D39`) on Warm Ivory (`#FFF8EE`): **4.8:1** (Exceeds WCAG AA).

## Copywriting Contract

All interactive elements must use specific, actionable verbs and nouns. Generic labels ("Submit", "OK", "Cancel", "Save", "Done") are forbidden.

| Element | Specific Copy |
|---------|---------------|
| Primary CTA (Intake Sheet) | "Extract Quote Breakdown" |
| Primary CTA (Quote Check Card) | "Commit {category} Quote" (e.g. "Commit Venue Quote", "Commit Catering Quote") |
| Primary CTA (Smart Inspector) | "Explore Scenario Comparison" |
| Secondary Action (Omission Adder) | "Add Omission to Plan" |
| Secondary Action (Source Inspection) | "View Verbatim Quote Excerpt" |
| Secondary Action (Manual Adoption) | "Add Excluded Amount Manually" |
| Re-open / Unlock Action | "Unlock / Replace Quote" |
| Sample Quote Chip 1 | "Royal Caterers Wedding Thali (₹950/plate)" |
| Sample Quote Chip 2 | "Shadi Mandap & Floral Decor (₹1,80,000)" |
| Sample Quote Chip 3 | "Cinematic Film & Photography (₹1,20,000+)" |
| Sample Quote Chip 4 | "Celebration Lawn & Banquet (₹2,50,000)" |
| Empty State (Quote Intake Textarea) | Heading: "No quote text entered yet" <br/> Body: "Paste a WhatsApp message, vendor email, or invoice breakdown, or tap a sample starter quote above." |
| Empty State (Ingested Quotes History) | Heading: "No quotes checked for this category" <br/> Body: "Drop a vendor estimate above to verify unstated taxes, overtime fees, and live plan impact." |
| Empty State (Dropped Items) | Heading: "All figures verified against source text" <br/> Body: "100% of numeric amounts in this quote were confirmed verbatim in the vendor text." |
| Error State (AI Extraction Timeout / Failure) | Problem: "Vendor quote extraction could not parse unstructured text." <br/> Solution path: "Showing standard quote template with manual rate fields. Review and adjust amounts below." |
| Error State (Unanchored Amount Detected) | Problem: "{count} figure excluded: ₹{amount} (no verbatim match in vendor text)." <br/> Solution path: "Review the original quote in the raw text drawer or click 'Add Excluded Amount Manually' to verify." |
| Error State (Plan Shortfall Delta) | Problem: "Selected quote exceeds available donor line capacity by ₹{shortfall}." <br/> Solution path: "Choose a shortfall calculation remedy: trim decor lines, adjust guest count, or expand total budget." |
| Destructive Confirmation (Unlock Quote) | Unlock / Replace Quote: "Unlock this committed quote? This will release the locked ₹{amount} allocation and re-open the category's primary booking task on your timeline. Your existing plan snapshot remains safely preserved." |

## Detailed Component Specifications

### 1. Quote Intake Slide-Over Sheet (`QuoteIntakeSheet.tsx`)
- **Container:** Radix/shadcn Sheet sliding from right (`max-w-xl w-full bg-warm-ivory border-l border-royal-plum/10 p-6 flex flex-col gap-6 overflow-y-auto`).
- **Header:**
  - Wordmark chip: `महफ़िल Quote Sandbox` in Tiro Devanagari Hindi.
  - Title: `Check Vendor Quote: {Category Name}` in Fraunces 20px SemiBold.
  - Subtitle: `Untrusted vendor quotes are safely quarantined with zero database access. Numbers are verified verbatim before touching your plan.`
- **Category Selector:** Segmented tabs or select pill row to quickly switch category context (`Catering`, `Venue`, `Decor`, `Photo & Film`, `Entertainment`, `Favors`).
- **Sample Starter Quotes Row:**
  - Header: `Try a realistic Indian celebration quote:` (`text-sm font-semibold text-royal-plum/70`).
  - 4 quick-action chips (`rounded-full bg-soft-ivory border border-royal-plum/10 hover:border-marigold px-3 py-1.5 text-xs font-medium text-royal-plum flex items-center gap-1.5 transition-all`).
  - Clicking any chip instantly loads the realistic quote text into the intake textarea.
- **Dual Input Ingestion Area:**
  - **Tab 1: Raw Text Paste (Default):**
    - Large textarea (`min-h-[160px] p-4 rounded-2xl bg-white border border-royal-plum/12 focus:border-royal-plum focus:ring-1 focus:ring-royal-plum text-sm text-royal-plum font-normal placeholder:text-royal-plum/40`).
    - Character counter: `(X characters)`.
  - **Tab 2: Screenshot / PDF Drop Zone:**
    - Drag-and-drop boundary (`border-2 border-dashed border-royal-plum/15 hover:border-marigold rounded-2xl p-6 text-center bg-soft-ivory/50 flex flex-col items-center justify-center gap-2 cursor-pointer transition-colors`).
    - Icon: `UploadCloud` (24px, Plum).
    - Subtext: `Drop JPEG, PNG, or invoice screenshot here, or tap to browse`.
    - File preview badge: shows thumbnail, filename, and file size with clear button.
- **Primary CTA:**
  - Pill button: `Extract Quote Breakdown` (`h-12 w-full rounded-full bg-marigold text-royal-plum font-semibold text-base shadow-md hover:scale-[1.01] active:scale-[0.98] transition-transform flex items-center justify-center gap-2`).
  - Loading State: Animated spinner with label `Analyzing verbatim text & unstated costs...` (disabled while processing).

### 2. Interactive Quote Check Card (`QuoteCheckCard.tsx`)
- **Container:** `rounded-3xl border border-royal-plum/10 bg-warm-ivory p-6 shadow-sm flex flex-col gap-5`.
- **Vendor Header:**
  - Top row: Vendor Name (Fraunces 20px SemiBold), category pill (`Catering`), and Ingestion Timestamp.
  - Payment Terms tag (if extracted): `Payment: 50% Advance, 50% on Event Morning`.
- **Package Tier Selector Tabs:**
  - Radix Tabs row displaying extracted packages (e.g., `Silver Package (₹1,50,000)`, `Royal Gold (₹2,20,000)`).
  - Selected tab has Marigold `#F7C873` wash with crisp Plum border and text.
  - Dynamically switches line items and tier totals in <50ms.
- **Extracted Line Items List:**
  - Each line displays item description, stated rate (`₹950/guest` or `₹1,80,000 flat`), and computed total in integer paise.
  - **Verbatim Source Pill:** Marigold pill `Source: "Rs 950 per plate"` with small quote icon. Clicking it opens the Raw Quote Drawer and smoothly scrolls to the exact highlighted excerpt in the source text.
- **Interactive Omission Adders Section:**
  - Header: `Unstated Costs & Category Omissions Detected` with info tooltip explaining standard Indian celebration overheads.
  - Toggle Chips Row:
    - Chip 1 (GST): `[ +18% GST estimate (+₹27,000) ]` or `[ +5% Catering GST (+₹11,875) ]`
    - Chip 2 (Generator): `[ + Generator Power Backup (+₹15,000) ]`
    - Chip 3 (Overtime): `[ + Overtime buffer after 10 PM (+₹10,000) ]`
  - Active chips are highlighted in Marigold; clicking toggles `isEnabled`, immediately updating the tier total in integer paise without network requests.
- **Dropped Items Amber Alert Pill (D-08):**
  - Rendered when unanchored figures are stripped: `rounded-2xl border border-amber-300 bg-amber-50/80 p-3.5 flex items-center justify-between gap-3 text-xs text-royal-plum`.
  - Icon: `AlertTriangle` in amber.
  - Text: `1 figure excluded: ₹45,000 (no verbatim match in quote text)`.
  - Action button: `Add Excluded Amount Manually` (ghost pill `px-3 py-1 rounded-full border border-royal-plum/15 font-semibold hover:bg-royal-plum/5`).
- **Real-Time Plan Impact Preview Bar (D-09):**
  - Live visual diff rendered directly above the commit action:
    - If quote is under baseline: `Saved ₹25,000 vs allocation — Surplus added to Contingency buffer`.
    - If quote exceeds baseline: `Requires +₹35,000 — Funded by trimming flexible lines: Misc (-₹20,000) and Entertainment (-₹15,000). Protected Moment (Catering) held firm.`
    - If quote triggers Permissive Shortfall: `Exceeds flexible donor capacity by ₹12,000 — Permissive Shortfall active. 3 calculation remedies available.`
- **Action Group:**
  - Primary CTA: `Commit {category} Quote` (`h-12 w-full rounded-full bg-marigold text-royal-plum font-semibold text-base shadow-md hover:scale-[1.01] active:scale-[0.98] transition-transform`).
  - Secondary Action: `View Verbatim Quote Excerpt` (opens raw text drawer).

### 3. Contextual Smart Inspector Slide-Over (`SmartInspectorSheet.tsx`)
- **Container:** Radix/vaul Sheet sliding from right on desktop or bottom sheet on mobile (`max-w-2xl w-full bg-warm-ivory border-l border-royal-plum/10 p-6 flex flex-col gap-6 overflow-y-auto`).
- **Editorial Banner:**
  - Header: `Mehfil Smart Inspector` with Tiro Devanagari Hindi ornament.
  - Title: Generative UI Layout Title (e.g. `Catering Vendor Comparison & Infeasible Buffer Analysis`).
  - Rationale Card: Soft Ivory container with Plum text detailing plain-language planning advice.
- **Generative UI Registry Container:**
  - Renders the model-selected allowlisted components (`VendorChecklist`, `IdeaGrid`, `QuoteReport`, `ScenarioComparison`) matching the active `GenerativeUISectionSchema`.
  - Strictly resolves all figures and dates from live client plan state via entity IDs (`lineIds`, `quoteIds`, `ideaIds`).
- **Fallback Toast & Degradation Banner (GENUI-03):**
  - If AI generation fails schema validation or times out, renders standard deterministic comparison layout with subtle toast: `Viewing standard comparison layout`.

### 4. Closed Registry Component 1: `VendorChecklist.tsx`
- **Props:** `{ lineIds?: string[]; highlightEntityId?: string; onSelectLine?: (lineId: string) => void }`
- **Visual Structure:**
  - Renders category cards in a vertical stack (`space-y-3`).
  - Each item displays Category Icon, Category Name, Allocated Baseline (`₹X,XX,XXX`), and Commitment Status:
    - **Open:** Soft Ivory pill with `Open — Check Quote` button.
    - **Committed:** Marigold pill `Committed: {Vendor Name} (₹{actualPaise})` with variance indicator (`Saved ₹25,000` or `+₹15,000 actual`).
  - Interactive Action: Clicking any item opens the `QuoteIntakeSheet` for that specific category.

---

### 5. Closed Registry Component 2: `IdeaGrid.tsx`
- **Props:** `{ ideaIds?: string[]; highlightEntityId?: string; onAdopt?: (idea: CuratedIdea) => void; onRetract?: (ideaId: string) => void }`
- **Visual Structure:**
  - 2-column responsive grid (`grid grid-cols-1 sm:grid-cols-2 gap-4`).
  - Each card features idea title, category badge, estimated cost range in integer Rupees, lead time, and donor displacement tag (`Funds from: Misc & Decor`).
  - Interactive Action: `Adopt Idea (+₹XX,XXX)` or `Retract Idea` button with instant spring feedback and budget re-balance.

---

### 6. Closed Registry Component 3: `QuoteReport.tsx`
- **Props:** `{ quoteId: string; onCommit?: (tierId: string, adders: string[]) => void; onUnlock?: () => void }`
- **Visual Structure:**
  - Comprehensive single-vendor dossier card (`p-6 rounded-3xl bg-warm-ivory border border-royal-plum/10`).
  - Full breakdown of verified line items, verbatim source anchors, active statutory adders (GST, generator), and stated inclusions/exclusions.
  - Summary row showing total integer paise and displacement preview.
  - Primary button: `Commit {category} Quote` or `Unlock / Replace Quote`.

---

### 7. Closed Registry Component 4: `ScenarioComparison.tsx`
- **Props:** `{ quoteIds?: string[]; lineId?: string; onSelectScenario?: (quoteId: string, tierId: string) => void }`
- **Visual Structure:**
  - Side-by-side multi-column comparison table (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`).
  - Column 1 vs Column 2 vs Column 3:
    - Header: Vendor Name & Selected Package Tier.
    - Rate Matrix: Flat vs Per-Guest rates calculated for `plan.brief.guestCount`.
    - Statutory Adders Comparison: Compares GST inclusion, power backup, and overtime buffers.
    - Impact on Plan: Displays net delta against category baseline and flexible donor displacement.
  - Primary Column Action: `Select This Scenario` (commits the respective quote and tier to the plan).

---

### 8. BudgetLineCard Integration & Commitment Indicators
- **Contextual Trigger:** Each `BudgetLineCard` in the workspace features a dedicated action:
  - If uncommitted: `Check Quote` (ghost pill `rounded-full border border-royal-plum/15 px-3 py-1.5 text-xs font-semibold hover:bg-royal-plum/5 text-royal-plum flex items-center gap-1.5`).
  - If committed:
    - Status Badge: Marigold pill `Committed: {VendorName}` (`rounded-full bg-marigold px-3 py-1 text-xs font-semibold text-royal-plum flex items-center gap-1`).
    - Variance Indicator:
      - If under budget: Cardamom Green text `Saved ₹25,000` (`font-semibold text-xs tabular-nums text-[#4A7C59]`).
      - If over budget: Soft plum text `+₹15,000 actual` (`font-semibold text-xs tabular-nums text-royal-plum/80`).
    - Secondary Action: `Unlock / Replace Quote` (opens confirmation dialog).

---

### 9. Primary Timeline Task Automatic Completion (D-11)
- When `Commit Quote` succeeds:
  - The primary booking task for that category transitions from open to completed (`isCompleted: true`).
  - Visual: Task row strikes through with subtle Cardamom Green checkmark and Marigold badge: `Booked via {VendorName} quote`.
  - Micro-Interaction: A celebratory confetti/particle burst springs around the task card accompanied by a reassuring toast: `{VendorName} quote committed! Booking task completed on your timeline.`
