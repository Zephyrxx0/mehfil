<threat_model>
## Threat Model Mitigation
- **T-04-07 (Excessive Swatch Selection Memory Load):** Users or automation spam hundreds of swatch selections. *Mitigation:* Strict UI limit of max 8 swatches enforced; 9th attempt plays a shake animation and is dropped; server API validates `z.array(z.string()).min(6).max(8)`.
- **T-04-08 (Destructive Accidental Baseline Reset):** Accidental tap on "Reset to Baseline" wipes user customizations. *Mitigation:* Explicit two-stage Radix `AlertDialog` confirmation; baseline reset creates an append-only forward version snapshot, ensuring full undo capability through version history.
- **T-04-09 (Alarming Failure UX Panic):** Model timeout causes scary red error alerts that confuse non-technical users. *Mitigation:* ADR-0007 Calm Degradation: StyleDNACard displays a gentle informative note with a subtle "Retry Extraction" button, keeping the rest of the workspace completely functional and calm.
</threat_model>
