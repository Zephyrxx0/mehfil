<threat_model>
## Threat Model Mitigation
- **T-04-01 (Asset Tampering & Missing Swatches):** Broken images or missing IDs cause client crashes. *Mitigation:* Swatch registry is validated against a static TypeScript contract; all 24 entries include inline SVG fallbacks; unit tests verify file existence and XML validity.
- **T-04-02 (Aesthetic Demographic Inference & Stereotyping):** Vision or LLM models infer religion, caste, or ethnicity from visual themes. *Mitigation:* Zod schema strictly forbids demographic fields (`.strict()`); prompt guidelines ban identity inference; dimensions represent purely sensory attributes (decor density, music, energy).
- **T-04-03 (Arithmetic Model Distortion & Floating Point Drift):** Model multipliers distort budget sums or introduce fraction paise. *Mitigation:* Models output relative weights only; pure TS engine clamps multipliers strictly to `[0.75, 1.25]` and runs Hare-Niemeyer largest-remainder apportionment in integer paise.
</threat_model>

- Zod schemas with strict bounds and identity safeguards.

- Protected Moment category locked to 1.25x floor multiplier.
- Integer paise sum invariant preserved exactly: $\sum \text{currentPaise} === \text{totalBudgetPaise}$.
- Deterministic Tier 3 heuristic extractor runs in <5ms without network calls.
</must_haves>
