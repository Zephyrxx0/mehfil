<threat_model>
## Threat Model Mitigation
- **T-04-04 (Infinite Schema Repair Loop):** Bad model outputs cause unbounded repair loops, draining budget and hanging requests. *Mitigation:* Schema repair is hard-capped at exactly 1 attempt at `temperature: 0`. Any subsequent failure triggers immediate tier escalation.
- **T-04-05 (Model Latency Freeze & Demo Disruption):** Slow cloud model responses (>15s) freeze the UI during live presentations. *Mitigation:* Enforce `AbortSignal.timeout(8000)` on Tier 1 and Tier 2; immediate fallback to Tier 3 ensures a complete, valid response in under 5ms.
- **T-04-06 (Missing Cloud Credentials Crash):** Absence of API keys in local dev, offline mode, or CI causes runtime crashes. *Mitigation:* Explicit environment key check bypasses network calls immediately and executes deterministic Tier 3 heuristic extractor with structured telemetry.
</threat_model>
