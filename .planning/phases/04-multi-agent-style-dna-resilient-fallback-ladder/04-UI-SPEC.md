## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Typographic rules:
- Body font family: `Plus Jakarta Sans`, font-weight 400, line-height 1.5.
- Label font family: `Plus Jakarta Sans`, font-weight 600, line-height 1.4.
- Heading font family: `Fraunces`, font-weight 600, line-height 1.2.
- Display font family: `Fraunces`, font-weight 600, line-height 1.2.
- Numbers and currency: `font-variant-numeric: tabular-nums` (`tnum`) in `Plus Jakarta Sans` formatted with Indian digit groupings (`₹5,00,000`).
- Text color is strictly Royal Plum (`#3A2442`). White text on pastel backgrounds is strictly prohibited (DESIGN.md §2.3).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8EE` (Warm Ivory) | Viewport background, modal surfaces, card canvas, clean negative space |
| Secondary (30%) | `#3A2442` (Royal Plum) / `#FBF2E3` (Ivory-900) | High-contrast typography (11.8:1 contrast), hairline borders (`rgba(58, 36, 66, 0.08)`), secondary card surfaces |
| Accent (10%) | `#F7C873` (Marigold) & `#F2A7B8` (Gulabi Rose) | Celebratory focus, selection feedback, and Protected Moment highlights |
| Destructive | `#D95D39` (Terracotta) | Destructive actions only: Reset to Baseline confirmation |

Accent reserved for:
1. Primary CTA button fill (`#F7C873` Marigold with `#3A2442` Plum text)
2. Protected Moment budget line highlight wash and lock badge fill (`#F2A7B8` Gulabi Rose)
3. Selected swatch card border ring (`#F7C873` 2px ring) and selected checkmark badge (`#F2A7B8` fill)
4. Swatch gallery celebratory counter pill when 6–8 swatches selected (`#F7C873` background)
5. Budget re-balance bar animated expansion fill and delta badge (`#F7C873`)
6. Style DNA palette preview dots (3–4 named celebration hues)

## UI Considerations

Applicable state considerations resolved: 9 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Swatch selection grid (0 selected) | ✅ covered | Counter displays "Pick 6 to 8 vibes (0/8 selected)"; Primary CTA button is disabled (`aria-disabled="true"`). Filter empty state renders documented empty state heading and body copy. |
| partial | Swatch selection grid (1–5 selected) | ✅ covered | Counter pill updates dynamically ("Pick 6 to 8 vibes (X/8 selected)"); Primary CTA button remains disabled with assistive tooltip "Select at least 6 vibes to continue". |
| populated | Swatch selection grid (6–8 selected) | ✅ covered | Counter pill shifts to celebratory Marigold tone ("Ready! X/8 vibes selected"); Primary CTA enables with spring bounce animation (`scale: [0.96, 1.04, 1]`). |
| overflow | Swatch selection grid (attempting 9th swatch) | ✅ covered | 9th selection is blocked; counter pill plays a subtle 200ms horizontal shake animation with helper text: "Maximum 8 swatches reached. Tap a selected swatch to deselect." |
| loading | Multi-agent extraction & plan reveal | ✅ covered | Two-beat reveal: Beat 1 shows instant v1 plan (<10ms) with subtle pulse skeleton on Style DNA card ("Analyzing visual vibes & balancing allocations..."); Beat 2 fires a 1.2s smooth spring re-balance bar animation as Style DNA finishes. |
| error | Multi-agent fallback escalation to Tier 3 | ✅ covered | If Gemma 4 and Gemini Flash fail or time out (8s), system falls back to Tier 3 heuristic extractor (<5ms). StyleDNACard renders calm degradation note with subtle "Retry Extraction" button; no disruptive error dialogs or broken screens. |
| reduced-motion | v2 Plan Reveal & Spring Re-balance | ✅ covered | When `prefers-reduced-motion: reduce` is active (`useReducedMotion() === true`), animation duration is 0ms with instant snap to target bar widths, counter numbers, and dimension sliders. |
| long-text | Protected Moment user quote (up to 200 chars) | 🧪 backstop | Textarea enforces `maxLength={200}` with live character counter `(X/200)`. Display cards render quote with `line-clamp-2` and full text in Radix Tooltip on hover/focus. |
| responsive | Style DNA Card & Retune Sheet | ✅ covered | Desktop ($\ge$1024px): StyleDNACard pinned at top of Pane 3 (col-span-3) above ChangeExplainer. Mobile (<1024px): accessible via dedicated 'style' tab and pinned header in the sliding bottom drawer. |
| zero-network | Offline / Missing API Key environment | ✅ covered | When `GOOGLE_GENERATIVE_AI_API_KEY` is absent, Fallback Ladder executes Tier 3 deterministic extractor instantly (<5ms) with dev console log, preserving full UI functionality without network calls. |
