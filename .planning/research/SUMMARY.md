# Research Summary: Mehfil (महफ़िल)

**Domain:** AI-Augmented Milestone Celebration & Event Planning Engine  
**Researched:** 2026-10-27  
**Overall confidence:** HIGH  

## Executive Summary

Mehfil addresses the core friction of celebration planning: budget, calendar, and vendors move together, but traditional tools treat them as disconnected silos while chatbots hallucinate numbers. By establishing the architectural boundary that **code owns numbers and dates while models propose weights and prose**, Mehfil provides mathematical reliability with human warmth.

The research establishes:
1. **Stack**: Next.js 15 (App Router), Supabase (Postgres with integer paise and RLS), Vercel AI SDK with Gemma 4 and Gemini Flash fallback, shadcn/ui with custom 3-hue festive tokens, Motion, GSAP, and Lenis.
2. **Differentiators**: Instant deterministic v1 baseline, Protected Moment budget immunity, prompt-quarantined Quote Check with verbatim source phrase verification, budget-neutral idea displacement, and compressed topological scheduling for short-notice milestones.
3. **Architecture**: 4-tier separation (Client, Boundary/Orchestrator, Pure TS Engine, Supabase Persistence) with a Closed Component Registry that binds components to engine entity IDs.
4. **Pitfalls Avoided**: Zero arithmetic hallucinations via integer paise; zero prompt injection via tool-less quote quarantine; zero blank loading screens via deterministic baseline instantiation.

## Phase Structure Recommendations

The findings directly inform the 7-phase implementation roadmap:

- **Phase 1: Pure TypeScript Core Engine & Archetypes** — Mathematical foundation (integer paise, largest-remainder solver, backwards topological calendar, and 3 event archetypes).
- **Phase 2: Database Schema, Versioning & Anonymous Capability Auth** — Supabase migrations for immutable plan versions, change records, and dual-link capability access.
- **Phase 3: Festive Design System & Celebratory Landing Page** — Tailwind token setup, shadcn/ui primitives, and the centerpiece Fraunces kinetic animated typography hero.
- **Phase 4: Multi-Agent Intelligence & 3-Tier Fallback Ladder** — AI SDK integrations for Style Analyst, Planner, and Idea Curator with zero-failure fallbacks.
- **Phase 5: Quote Check, Quarantine & Interactive Review** — Prompt quarantine pipeline, verbatim source phrase matching, omission detection, and interactive commitment.
- **Phase 6: Closed Registry Generative UI & Workspace Shell** — Desktop 3-pane / mobile 4-tab workspace, entity ID binding, and plain-language change explanation panel with undo.
- **Phase 7: End-to-End Invariants, Obscura Browser Audit & Polish** — Mathematical property testing, accessibility validation, and demo seeding.
