# Architecture decision records

Each file in this folder records one decision: the situation, what was decided, and the consequences. For a map of the code, see [ARCHITECTURE.md](../ARCHITECTURE.md).

Records that were replaced or extended later carry a Status line near the top. The Status column below repeats what each file states about how it relates to the others, and says "Not stated" where a file has no Status line. Where code and a record disagree, the code is what runs.

## Adding a record

Number it with the next free four-digit prefix and use a short kebab-case name, as the existing files do. Existing records follow the order Title, summary paragraph, Context, Decision, Consequences. Add a Status line under the title when a record replaces or extends another, and update the table above to match.
